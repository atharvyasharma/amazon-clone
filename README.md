# 🛒 Amazon Homepage Clone

A front-end clone of the Amazon homepage built using **HTML5 and CSS3**. This project recreates the visual layout of Amazon's shopping homepage, including its navigation bar, search section, hero banner, product category cards, and footer.

## ✨ Features

- **Navigation Bar:** Amazon logo, delivery location, search bar, account section, returns and orders, and shopping cart.
- **Secondary Navigation Panel:** Includes Today's Deals, Customer Services, Registry, Gift Cards, and Sell.
- **Hero Section:** Displays a promotional banner with a message about shopping on Amazon India.
- **Product Categories:** Eight category cards covering:
  - Gaming
  - Home Essentials
  - Travel Essentials
  - Fashion
  - Sports
  - Watches
  - Toys
  - Wireless Technology
- **Interactive Hover Effects:** Border effects on navigation elements and the search bar.
- **Footer Section:** Includes company information, useful links, and copyright information.
- **Font Awesome Icons:** Used for the search, location, menu, and shopping cart icons.

## 🛠️ Technologies Used

- **HTML5** – Structure and content of the webpage.
- **CSS3** – Styling, Flexbox layout, spacing, colors, and hover effects.
- **Font Awesome** – Navigation and shopping icons.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the cloned project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the Amazon-inspired homepage.
